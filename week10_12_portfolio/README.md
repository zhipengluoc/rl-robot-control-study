# 阶段 5 ｜ W10-W12 ｜ 求职作品集精修

> **这 3 周不是学新东西，是把前 9 周做的东西包装成"能拿出去看"的状态**。
> 目标是让招聘 / 教授 / 面试官打开你 GitHub 5 秒内决定"这人值得聊"。

## 核心原则

1. **质量 > 数量**。一个精雕细琢的项目胜过 5 个半成品。
2. **可视化优先**。视频、gif、学习曲线、架构图——非技术人员也能感受到价值。
3. **故事大于代码**。README 要讲清楚"为什么做、怎么做、做出了什么"，而不只是"怎么跑"。

## W10：选择主打项目并整理

### 选项分析

从前 9 周的产出里挑 1 个深做：

| 选项 | 选它的理由 | 不选它的理由 |
|---|---|---|
| **A. MJX 四足 locomotion** | 最热门方向，工业界要 locomotion 的多 | 视觉效果对比"操作"稍弱，需要好的视频剪辑 |
| **B. robosuite 多任务操作** | 视频效果直观，VLA 时代相关 | 技术深度可能没 A 那么硬核 |
| **C. PPO/SAC 实现 + 实施细节文档** | 显示算法功底，独立性强 | 不直接绑机器人，对机器人岗位说服力略弱 |

**我的建议**：

- 求职**机器人公司算法岗 / RL 工程师**：选 A。Unitree、宇树、星动、银河通用、Boston Dynamics、Skild AI 都做这个。
- 求职**具身智能 / VLA 方向**：选 B 然后扩展加入模仿学习对比，或者 A + 一段"我这个 RL 策略和 IL baseline 对比"的小实验。
- 求职**RL 算法 / 通用 ML 岗**：选 C 配合两个机器人 demo 作为佐证。

选定后建一个**独立的 GitHub 仓库**（不是放在这个学习仓库里），名字要好（比如 `mjx-quadruped-locomotion`、`rl-from-scratch-pytorch`）。

## W11：打磨

### 主打项目 README 必须包含

```markdown
# Project Title

> 一句话：项目做了什么 + 关键指标

[gif/video demo]                <- 第一屏必须有

## 亮点
- 用 X 实现了 Y，达到 Z%
- 探索了 A vs B 的对比
- 验证了 ...

## 安装
[复现指令，要能 5 分钟跑起来]

## 使用
[最小示例]

## 实验结果
[表格 + 图]

## 实现细节
[关键的 design choice，每个都说"为什么这么做"]

## 致谢 / 参考
```

### 录视频

- 时长：30-90 秒最佳
- 加文字标注解释正在做什么
- 配上学习曲线 / 数字
- 工具：QuickTime + iMovie 完全够用

### 写博客（**强烈推荐**）

把项目里最有意思的部分（比如"为什么 reward shaping 这样设计"、"sim2real gap 怎么发现的"）写成一篇 1500-3000 字博客，发到：

- 知乎（面向中文圈）
- 个人博客 / Medium / Substack（面向英文圈）
- 转发到 Twitter / 小红书

**博客是简历最大的差异化**。绝大多数候选人没有，有的会被立刻记住。

## W12：求职动作

### 简历

- 项目部分用 STAR 法则：Situation - Task - Action - Result
- 量化指标：训练时间、收敛 step、性能提升 %
- 技术栈一行写清楚（PyTorch、JAX、MuJoCo、MJX、stable-baselines3 等）

### 自我介绍

练 3 个版本：

- 30 秒：一句话项目 + 你解决了什么问题
- 2 分钟：背景 + 主打项目细节 + 你为什么对具身智能感兴趣
- 5 分钟：完整介绍，加一些技术深度

### 面试准备

去 `interviews/job_prep.md` 一项一项过。

### 投递

机器人 / 具身智能岗位（2026 年活跃名单）：

- 国内：宇树、银河通用、星动纪元、智元、有鹿、Galbot、字节 Seed Robotics、字节 ByteDance Research、地平线机器人 BU、华为 RoboGPT、阿里达摩院、腾讯 Robotics X
- 海外：Boston Dynamics、Skild AI、Physical Intelligence (π)、1X、Figure、Apptronik、Tesla Optimus、Anduril、Toyota TRI
- 学术：申博 / RA / 客座

每周投 5-10 家，跟踪进度。
